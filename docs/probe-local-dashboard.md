# 探针本地只读页面

Go 探针提供独立的本地页面；按用户后续要求，不实现云端探针详情页，不增加状态报告、Durable Object 数据或 D1 行数。

`GET /api/probes/config` 的 v1 响应新增可选 `probe: {name, location}`、`display_monitors`（已分配目标的 ID/显示名/方法/暂停/间隔/超时）及检查目标 `name`。暂停目标只进入显示元数据；活跃 `monitors` 保留原检测字段。显示元数据不包含 URL、鉴权头、请求体、通知配置或其他探针目标。自动名称从 Cloudflare 请求上下文生成，管理员名称优先；无需新增查询。旧探针会忽略新增字段，新探针仍接受旧配置缓存。名称变更不会重启在途检测。

默认本地入口为 `127.0.0.1:9187`，内嵌 HTML/CSS/JS，断网及 D1 额度不足时仍可查看本机队列与缓存。配置无法同步时仍显示最近成功同步的信息；首次升级的旧缓存缺少显示名/暂停目标列表时，等下一次成功配置同步后补齐。数据库预算为 1 GiB，包含队列和滚动历史，并保留页与事务开销余量。

本地验证：Worker 原 208 项回归通过，新增配置元数据用例及其所在 15 项探针测试通过；Go 竞态、无遥测构建、真实二进制断网/ACK/重启、390px 手机时间轴检查通过。生产版本与实机升级结果记录在部署报告；本页不公开实机队列数据。
