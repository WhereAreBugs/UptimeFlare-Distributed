# Status Logo

The default status-page logo uses the Suzume Telegram sticker character reference supplied by the site owner: mint-green bob hair, blue eyes, cat-ear hoodie and yellow hair clip. It combines the character with the capital S in `Status`.

- Generated with the built-in imagegen tool using the supplied sticker sheet as an identity reference; the private input sheet is not committed.
- Editable generation source: [status-suzume-source.png](../assets/branding/status-suzume-source.png), 2169 × 725 PNG with alpha.
- Web asset: [status-suzume.webp](../public/brand/status-suzume.webp), 760 × 254 WebP, 44,706 bytes with alpha. Sharp only resizes and encodes the generated artwork for delivery.
- The existing logo field can override the default. This release does not rewrite saved monitoring or page configuration.

## Generation prompt

```text
Use case: logo-brand.
Create ONE final horizontal transparent logo for a website header, using the attached Telegram Suzume sticker sheet solely as the character identity reference. Do not reproduce the sticker sheet.
The reference character is a cute chibi with short pale mint-green bob hair, large blue eyes, pale gray/off-white cat-ear hoodie with turquoise inner ears, and one distinctive yellow angular hair clip at the side. Preserve these recognizable details and the bold, clean charcoal outline. Use a friendly, playful small smile.
Integrate the character directly into the left part of the wordmark: her head and two small hands peek over and hug the capital S, rather than a disconnected mascot next to the text. The hoodie shoulders form a clean compact lower-left silhouette. Keep all six letters fully readable.
Exact sole text, verbatim: "Status" (capital S then lowercase t a t u s). No other text, no clothing lettering, no watermark.
Use a rounded, bold, custom geometric sans wordmark, dark forest-teal letter fill and crisp charcoal outlines that complement the mint character, with a restrained light keyline for contrast. Flat colors, minimal detail, professional crisp silhouette; no photorealism, no busy shading, no gradients or glow.
Composition: a wide, tightly composed horizontal lockup roughly 3.3:1 including artwork, all artwork fully inside the canvas with small even transparent padding. The character should be similar in height to the lettering and should not dominate it, leaving the word easy to read at 190px wide by 56px high. No extra icons, doors, chairs, hearts, props or scene. Genuine transparent alpha background, no white rectangle and no checkerboard artwork.
```
